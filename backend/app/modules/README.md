# Backend Modular - NOVA SOUND

El backend se divide en tres módulos.

## Responsables

### Diego - Almacén
- Empaque
- Cajas
- Embarques

### Aldair - Calidad
- Pruebas funcionales
- Inspecciones
- Defectos
- Retenciones y retrabajos

### Carlos - Producción
- Autenticación y usuarios
- Órdenes de producción
- Ensamble
- Cierres de turno

## Organización

Cada integrante será responsable de implementar:

- router.py
- schemas.py
- service.py
- repository.py

Cada desarrollador trabajará en su propia rama.

Los cambios a la base de datos o archivos compartidos
deberán coordinarse con el equipo.
